# 实机相机接入

日期：2026-09-29

## 支持范围

| 类型 | 接入方式 | 前置条件 |
| --- | --- | --- |
| 普通 USB/UVC | Windows Media Foundation；Linux V4L2 | 系统能识别摄像头，允许桌面应用访问相机；Linux 用户有视频设备权限 |
| 海康工业相机 | MVS C SDK，GigE Vision / USB3 Vision | 安装对应架构的 MVS SDK 与相机驱动，厂商客户端能够采图 |
| 大恒工业相机 | Galaxy C SDK，GigE / USB Vision | 安装 Galaxy SDK 与相机驱动，厂商客户端能够采图 |

这里是三类接入实现，不代表所有品牌、所有型号、所有像素格式都已实测。开发环境未连接可用实机，自动化测试使用测试用 SDK 与确定性后端；具体设备实拍验收仍需在目标电脑执行。

## 使用步骤

1. 工业相机先在厂商客户端验证采图，再关闭客户端，避免独占冲突。网口相机需确认电脑与相机网段可达；软件不修改电脑网卡配置。
2. 打开“相机采集”算子，选择“相机”页并刷新设备。
3. 选择设备；选择项按厂商序列号或系统设备路径绑定，不使用易变化的枚举序号。
4. 工业相机可设置曝光（微秒）、增益和触发模式。曝光 0、增益 -1 表示保持相机当前值。设备实际范围在执行时校验。
5. 默认连续采集模式。选择“软件触发”时，每次取帧仅发送一次触发；“外部触发（Line0）”需要相机支持并正确接线。
6. 设置单帧超时，然后运行算子/流程，图像通过现有显示区输出。长曝光需使用更长超时。
7. 保存工程，设备标识、超时、曝光、增益和触发配置随工程保存。旧工程自动使用默认值。

USB 后端目前使用系统默认/协商分辨率（Linux 优先请求 640×480），工业分辨率、ROI、帧率、网络地址和高阶触发参数仍由厂商客户端设置。软件不承诺替代全部厂商控制面板。

## SDK 路径与故障提示

相机页会分别显示三个后端的扫描状态。安装工业 SDK 不影响其他类型相机使用；缺失 SDK 不会阻止软件启动。

自动发现优先读取厂商运行库环境与常见安装目录，再使用系统动态库搜索路径。特殊安装目录可设置系统环境变量后重启 XVision：

- XVISION_MVS_LIBRARY：MvCameraControl.dll（Linux 为 libMvCameraControl.so）的绝对路径。
- XVISION_GALAXY_LIBRARY：GxIAPI.dll（Linux 为 libgxiapi.so）的绝对路径。

安装包不携带厂商 SDK、驱动或测试用动态库。SDK 的其他依赖也必须通过厂商安装程序正确安装；仅复制一个 DLL 通常不足以完成部署。

海康调用 SDK 像素转换接口处理 Mono8/RGB/BGR 之外的格式；大恒支持 Mono8、Bayer GR/RG/GB/BG 8 位、RGB8、BGR8。大恒其他位深会明确报出格式并提示在 Galaxy 中切换，不把原始数据误当图像。

## 实机验收清单

记录品牌/型号/序列号、连接类型、操作系统、SDK 版本与选定像素格式，然后执行：

- 扫描、连接、首帧、重复 100 次采集，确认颜色与方向正确。
- 曝光与增益生效；软件触发一次一帧；外部触发有信号得图、无信号按时超时。
- 拔线后明确报错且下游无旧图；重连刷新后可重新采图。
- 厂商客户端占用、权限缺失、SDK 缺失时诊断清楚，界面保持响应。
- 保存并重开工程，确认绑定未漂移；两台同型号相机不能串图。
- 连续运行 30 分钟，记录平均/P95 采集时延、CPU 与内存，再与厂商客户端同分辨率比较。
